# Firefly Canvas 功能 UX QA / Heuristic Evaluation 报告

> 里程碑：M1–M5 全部交付后执行（feature/canvas-m1 … feature/canvas-m5）
> 方法：Nielsen 10 项可用性启发式 + 状态/反馈/导航/弹层/微交互专项走查
> 结论：**通过**（含 2 项本轮已修复的 papercut；5 项已知限制列入后续 backlog）

| 区域 | 覆盖 |

## 1. 启发式逐项核查

### H1 系统状态可见性 ✅
- 自动保存状态常驻工作台头部（保存中…/已自动保存/保存失败，点击重试）；aria-live 播报
- 插入素材/插入画布全流程有进度态（导入中 spinner）与结果态（成功面板、错误横幅）
- 视频节点加载状态：靠近时自动载入 → 正在载入 → 就绪/失败（重试按钮），与 TaskCard 行为一致
- 系统在线/同步中断指示（沿用既有 system-live）

### H2 系统与现实世界匹配 ✅
- 画布交互对齐 Figma/Miro/FigJam 惯例：滚轮缩放、空格临时平移、中键平移、双击空白创建文本、双击标题重命名、双击文本编辑、四角缩放（媒体保比例）、拖把手连线、小地图拖拽跳转、左下角工具坞
- 文案全部中文、动词明确（新建画布/插入画布/打开画布/加载更多）

### H3 用户控制与自由 ✅
- 所有操作可取消：Escape 取消重命名/编辑/连线/清空选中/关闭弹层；删除有确认框且默认焦点在「取消」
- 撤销/重做（Ctrl/Cmd+Z/Y）覆盖节点增删改、连线、背景切换（180ms 合并、50 步）
- 框选支持 Shift 加选/减选；删除节点级联删除连线

### H4 一致性与标准 ✅
- 样式沿用 Firefly 既有设计体系（archive-card/confirm-dialog/feedback 模式），未引入新 UI 依赖
- 错误反馈格式统一：色块横幅 + 可重试按钮；删除确认统一 confirm-dialog
- 相对时间/节点计数/空态文案风格与资产页一致

### H5 错误预防 ✅
- 连线自连/分组连线被静默拒绝（不产生无效连接）
- 复制保留组内连线；粘贴 id 全量重映射（不产生悬空引用）
- 图片插入按钮对「外部链接素材/处理中」禁用并给出 title 说明
- 输入框/IME 组合期间快捷键不触发（防误删/误粘贴）

### H6 识别而非回忆 ✅
- 工具栏按钮全部带 icon + title/aria-label；快捷键弹层列出全部快捷方式（kbd 样式）
- 空画布引导提示（「双击空白处添加文本节点」）
- 悬停节点时关联节点高亮、拖拽时分组落点高亮、连线时吸附高亮——操作意图即时可见

### H7 灵活高效 ✅
- 快捷键完整（A 全选 / C 复制 / V 粘贴 / Delete 删除 / Z 撤销 / Y 重做 / Escape）
- 双入口插入媒体：资产页批量管理时可「插入画布」，工作台内随时「插入素材」
- 小地图快速定位；缩放滑杆 5–500% + 重置

### H8 美观而克制的设计 ✅
- 画布采用独立暗色主题变量（--canvas-*），与 Firefly 现有暗色体系一致
- 无多余装饰；选中/悬停/关联状态通过描边+阴影区分，符合认知负荷

### H9 帮助用户识别、诊断并从错误中恢复 ✅
- 保存失败：状态条变红 + 点击重试 + title 显示错误详情；网络恢复自动重试
- 409 冲突：横幅明示「已在其他窗口被修改，已载入最新版本」，避免静默丢数据
- 媒体迁移失败（425）：节点显示「素材迁移失败，请删除节点后重新插入」
- 视频加载失败：重试按钮 + 播放位置保留；断网时提示「网络恢复后自动重连」

### H10 帮助文档 ✅
- README.md 增加画布功能说明、目录结构、快捷键表、媒体铁律
- docs/canvas-integration-plan.md 作为唯一真相来源全程维护

## 2. 专项走查：状态 / 反馈 / 导航 / 弹层 / 微交互

### 状态
- 列表：加载骨架（6 卡 shimmer）→ 内容/空态/错误（可重试），无闪烁
- 工作台：载入中 → 就绪/错误；文档变更 → 保存中 → 已保存
- 节点：空/媒体加载/失败三态均有明确视觉与文案

### 反馈
- 每次交互均有即时反馈：拖拽跟随、框选实时矩形、连线虚线预览+吸附、缩放光标锚定
- 破坏性操作（删除画布/删除项目）统一确认框 + 危险色按钮

### 导航
- 列表 ↔ 工作台双向（返回「画布列表」按钮 + 卡片进入）
- 资产页插入成功后可直接「打开画布」；侧栏「新建画布」任意视图可用
- 浏览器前进/后退支持（history.pushState 架构，popstate 监听）

### 弹层
- 全部弹层：点击遮罩关闭、Escape 关闭（忙碌态禁用）、aria-modal/labelledby、移动端底部贴边布局
- 快捷键弹层、插入素材弹层、画布选择器、删除确认——四类弹层视觉层级一致

### 微交互
- 节点 hover/选中/关联三态描边过渡 200ms；拖拽落点高亮；连线 16px 命中层降低误触
- 卡片 hover 上浮、骨架 shimmer、按钮 hover 反馈——与既有资产页一致
- prefers-reduced-motion 全局降级（styles.css 已有）

## 3. 本轮修复的 papercut

| 问题 | 修复 |
|---|---|
| 双击空白无任何反应（空画布缺乏引导） | 双击空白创建文本节点并立即进入编辑（editRequest 机制）；空画布显示引导提示 |
| 工作台头部残留开发文案「已载入 · 自动保存即将接入」 | 替换为真实保存状态（保存中/已保存/失败重试/冲突） |
| 工具栏在窄屏溢出 | 允许横向滚动（隐藏滚动条） |
| 409 冲突无提示地覆盖本地改动 | 冲突横幅 + 载入最新版本 + 重置撤销历史 |

## 4. 已知限制（后续 backlog）

1. **触摸设备的节点缩放**：resize 走 mouse 事件，触摸拖拽不触发 mousemove。桌面优先产品，后续可迁移 pointer 事件统一。
2. **弹层焦点陷阱**：弹层未实现 focus trap 与焦点归还，键盘 Tab 可能移出；遮罩已阻断指针交互，风险低。
3. **极速关页的最后改动**：beforeunload 使用普通 fetch（未用 keepalive），极端快速关页可能丢失最后一个 800ms 内的改动；visibilitychange(hidden) 已覆盖绝大多数关闭/切页场景。
4. **插入素材列表无分页**：视频取全部 /api/generations，图片取前 60；量级上来后加分页/虚拟滚动。
5. **多窗口同画布协作**：不做字段级合并，后保存方被 409 拦截并载入最新版本（符合 P0 决策）；如需实时协作另立项目。

## 5. 结论

画布功能达到商业产品级可用性基线：交互遵循主流平台惯例（Figma/Miro 心智模型），
状态与反馈完整，错误可恢复，破坏性操作有防护；本次 QA 未发现阻塞性问题。
建议后续以真实使用数据（保存失败率、撤销使用频次、插入转化）持续迭代。
